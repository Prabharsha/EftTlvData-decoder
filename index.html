    How Tag 120 is packed

    Field 120 is a flat string of sub-fields, each laid out as TAG (3 digits) + LENGTH (3 digits) + VALUE (LENGTH chars), repeated until the string ends. The decoder reads it exactly the way MessageConversionHelper.breakEftTlvData() does in the CEFT core.
